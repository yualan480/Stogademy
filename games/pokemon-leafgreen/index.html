Pokémon LeafGreen

Play your own Game Boy Advance copy inside Orbit.

Choose your own Pokémon LeafGreen .gba cartridge file. It remains on your device and is never uploaded. This browser can remember it for future visits. The game ROM is not included.

Ready to choose a game file.

Save through the game’s menu before leaving. Export a .sav file for backup. Your chosen game file is remembered only in this browser and can be removed with Forget game file.

Keyboard: arrows move · Z = A · X = B · Enter = Start · Backslash = Select · A/S = L/R.

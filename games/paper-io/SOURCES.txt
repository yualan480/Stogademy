Game source from that repository. The checked-in binary is a starter template; Orbit compiled main.ts and pinned pxt.json dependencies using pxt-arcade 4.2.1 and pxt-core 13.2.1.
MakeCode simulator HTML/CSS template from https://trg-arcade.userpxt.io/v1.4.41/---simulator and its linked cdn.makecode.com assets; Runtime JS is built/sim.js and built/common-sim.js from pxt-arcade 4.2.1, plus built/pxtsim.js from pxt-core 13.2.1. Microsoft runtime notices retained.
Orbit localizes runtime paths, validates simulator messages, and embeds the game without external navigation.
